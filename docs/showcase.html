How It Works

Every request passes through four resilience layers before hitting the wire

Your App — client.get('/users')
Priority Queue — caps concurrency, schedules by priority
Circuit Breaker — trips on consecutive failures, auto-recovers
Retry — exponential backoff with jitter, evicts stale connections
HTTP Engine — axios (TS) / reqwest (Rust) / fetch (browser)

Quick Start

Replace axios.create() with one line

// Install
npm install @eric8810/catcher-http @eric8810/catcher-ws
// HTTP — with retry, circuit breaker & connection pooling
import { createHttpClient } from '@eric8810/catcher-http'

const client = createHttpClient({
  baseURL: 'https://api.example.com',
  keepAlive: true,
  retry: { attempts: 3 },
  circuitBreaker: { failureThreshold: 5, resetTimeout: 30_000 },
  concurrency: 10,
})

const data = await client.get('/users/1')
const result = await client.post('/messages', { text: 'hello' })

// Per-request overrides
await client.get('/analytics', { retry: false, timeout: 5000 })

// Dynamic interceptors
client.interceptors.request.use(config => {
  config.headers.Authorization = 'Bearer ...'
  return config
})
// WebSocket — compression + reconnect + multi-endpoint racing
import { createResilientWS } from '@eric8810/catcher-ws'

const ws = createResilientWS({
  url: ['wss://cn.example.com', 'wss://sg.example.com'],
  perMessageDeflate: true,
  reconnect: { initialDelay: 1000, maxDelay: 30_000 },
})

ws.addEventListener('message', e => console.log(e.data))

// Binary codec — 2-4× faster than JSON
import { pack, unpack } from '@eric8810/catcher-ws'
ws.send(pack({ event: 'msg', data }))
// SSE — AI streaming (OpenAI / Anthropic / Gemini compatible)
import { createSSEStream } from '@eric8810/catcher-http'

const stream = createSSEStream({
  url: 'https://api.openai.com/v1/chat/completions',
  method: 'POST',
  headers: { Authorization: 'Bearer ...' },
  body: { model: 'gpt-4', messages: [{ role: 'user', content: 'Hello' }], stream: true },
})

for await (const line of stream) {
  if (!line.startsWith('data:')) continue
  const payload = line.slice(6)
  if (payload === '[DONE]') break
  process.stdout.write(JSON.parse(payload).choices[0]?.delta?.content ?? '')
}
// loop ends = connection closed, no manual cleanup

Features

🔄

Auto-Retry

Exponential backoff with ±25% jitter. Destroys stale keepAlive sockets before retry — never reuse a dead connection.

⚡

Circuit Breaker

Trips on consecutive failures, auto-recovers after reset timeout. Prevents cascading failure storms in burst loss conditions.

🔗

Connection Pooling

Shared HTTPS Agent with keepAlive, DNS caching, idle socket eviction. One agent → 3× throughput.

📶

Resilient WebSocket

perMessageDeflate compression, exponential backoff reconnect, multi-endpoint racing. Survives network interruptions.

🗜️

Binary Codec

Built-in msgpack: true config — 2-4× faster than JSON, 47% smaller payloads. Zero NAPI boundary overhead; also exposes standalone pack/unpack.

🎯

Priority Queue

POST before prefetch. Your chat messages go out before avatar images. Concurrency-aware scheduling.

✂️

Dynamic Interceptors

use() / eject() / clear() at runtime. LIFO request chain, FIFO response chain. Per-request overrides for retry, timeout, signal.

🛡️

Route Black Hole Detection

Silently dropped packets? CB trips, connections evicted, automatic recovery when network returns.

📡

Server-Sent Events (SSE)

AI streaming made simple. createSSEStream for one-shot chat, createSSEClient for long-lived push with auto-reconnect, Last-Event-ID resume, and circuit breaker protection.

🌐

DNS Cache

StaleAwareDnsResolver — 676× cache-hit speedup, stale-while-revalidate serves cached entries while refreshing in the background, stale-on-error fallback for resilience.
