# 06 — WebSocket 客户端

> 对应源文件：`src/ws/client.ts`（151 行）+ `src/ws/reconnect.ts`（34 行）+ `src/ws/multi-endpoint.ts`（64 行）

## 职责

创建带多层增强的 WebSocket 客户端：
- `perMessageDeflate` 压缩
- 可配置握手超时
- 指数退避 + jitter 自动重连
- 多端点竞速连接（去最快）

## 核心导出

### createResilientWS(options) → ResilientWS

```typescript
import { createResilientWS } from 'catcher/ws'

const ws = createResilientWS({
  url: ['wss://cn.example.com', 'wss://sg.example.com'],
  protocol: ['auth-token'],
  perMessageDeflate: { threshold: 1024 },  // >1KB 消息压缩
  handshakeTimeout: 10_000,
  maxPayload: 1024 * 1024,
  reconnect: {
    initialDelay: 1000,
    maxDelay: 30_000,
    backoffMultiplier: 2,
    maxAttempts: 20,
  },
  raceCount: 3,
  headers: { 'User-Agent': 'catcher/0.1.0' },
  rejectUnauthorized: false,
})

ws.addEventListener('open',    () => console.log('connected'))
ws.addEventListener('message', (e) => console.log(e.data))
ws.addEventListener('close',   (e) => console.log('closed', e.code))
ws.addEventListener('error',   (e) => console.error(e))
```

interface ReconnectStrategy {

## 状态机

```
          ┌──────────────┐
          │ DISCONNECTED │ ← 初始 / 主动关闭
          └──────┬───────┘
                 │ connect()
          ┌──────▼───────┐
    ┌─────│  CONNECTING  │
    │     └──────┬───────┘
    │            │ socket.on('open')
    │     ┌──────▼───────┐
    │     │  CONNECTED   │
    │     └──────┬───────┘
    │            │ socket.on('close') / error
    │     ┌──────▼───────┐
    │     │RECONNECTING  │ ← delay = nextDelay()
    │     └──────┬───────┘
    │            │ reconnect.connect()
    │            │       OR
    │            │ maxAttempts exhausted
    │            ▼
    └──── DISCONNECTED
```

## 连接流程

```
createResilientWS(config)
  │
  ├─ urls.length > 1 ?
  │  ├─ YES → raceEndpoints(urls, options)
  │  │         ├─ 同时连接所有 endpoint
  │  │         ├─ 第一个 'open' → 关闭其余 → setupSocket(winner)
  │  │         └─ 全部失败 → 进入重连
  │  └─ NO  → new WebSocket(url, options) → setupSocket(socket)
  │
  ▼
setupSocket(socket)
  ├─ 设置握手超时 timer
  ├─ socket.on('open')   → 清除 timer, reset reconnect, emit open/statuschange
  ├─ socket.on('message') → emit message event
  ├─ socket.on('close')   → 清除 timer, emit close/statuschange, schedule reconnect
  └─ socket.on('error')   → 清除 timer, emit error event
```

## 关键技术细节

### perMessageDeflate 配置

```typescript
wsOptions.perMessageDeflate = {
  zlibDeflateOptions: { level: 6, memLevel: 7 },
  threshold: 1024,              // 小于 1024 字节不压缩
}
```

经验收益：带宽减少 70~80%，CPU 增加可忽略。

### 握手超时

`handshakeTimeout` 传入 ws 库的 `ClientOptions.handshakeTimeout`，默认 10s。超时后主动 `socket.close(4000, 'Handshake timeout')`。

### 重连延迟计算

```typescript
delay = initialDelay * multiplier^(attempt-1) + randomJitter(±25%)
delay = min(delay, maxDelay)
```

| attempt | delay (initialDelay=1000, multiplier=2, maxDelay=30000) |
|---------|------|
| 1 | ~1000ms ±250ms |
| 2 | ~2000ms ±500ms |
| 3 | ~4000ms ±1000ms |
| 4 | ~8000ms ±2000ms |
| 5 | ~16000ms ±4000ms |
| 6+ | ~30000ms ±7500ms (cap) |

## ResilientWS API

```typescript
interface ResilientWS extends EventTarget {
  send(data: string | Buffer): void
  close(code?: number, reason?: string): void
  readonly readyState: number          // 0=CONNECTING, 1=OPEN, 2=CLOSING, 3=CLOSED
  readonly url: string                  // 当前连接 endpoint
  readonly status: 'CONNECTING' | 'CONNECTED' | 'CLOSED'
  addEventListener(type: 'open' | 'close' | 'message' | 'error', listener): void
  removeEventListener(type: string, listener): void
}
```
