# Catcher 0.4.0

发布日期：2026-09-21

## 重点变化

Flutter iOS 插件正式接入 Swift Package Manager（SPM）。Flutter 工程启用 SPM 后，`catcher_core` 不再依赖 CocoaPods 安装 iOS 原生依赖，Xcode 会通过 `ios/catcher_core/Package.swift` 直接链接 `catcher_ffi.xcframework`。

## 兼容性

- 保留现有 `catcher_core.podspec`，仍在使用 CocoaPods 的工程不受影响。
- Flutter 检测到插件提供 `Package.swift` 后，会自动从 CocoaPods 安装列表跳过该插件，避免同一模块被重复链接。
- Dart API 与 0.3.19 保持一致，无破坏性变化。

## 发布产物

- `packages/catcher_core/ios/catcher_core/Package.swift`：SPM 包入口，产品名使用 `catcher-core`，通过 binary target 暴露 `catcher_ffi.xcframework`。
- `packages/catcher_core/ios/catcher_core/catcher_ffi.xcframework`：SPM 包内嵌的 iOS 二进制，由本地构建脚本和 CI release 流程生成，并纳入 pub.dev 打包。
- 所有 npm、Rust、NAPI 和 Flutter 包版本统一同步到 `0.4.0`。

## 验证

- Flutter iOS 模拟器构建通过，`catcher_ffi.framework` 被 Xcode 嵌入 `Runner.app/Frameworks/`。
- SPM 接入后 `catcher_core` 从 CocoaPods `Podfile.lock` 移除，未出现重复模块链接。
- `dart pub publish --dry-run` 通过，SPM 包与 iOS 二进制均包含在发布内容中。
- Rust workspace check、clippy 和测试保持绿色。
