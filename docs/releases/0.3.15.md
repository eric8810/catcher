# Release Notes — v0.3.15

> 发布日期：2026-06-13 · 对比基线：v0.3.13 · 跳过 v0.3.14
>
> 新增系统代理自动检测：`proxy.mode = "system"`。
>
> 📌 **唯一的 breaking change**：`ProxyConfig.url` 从 `String` 变为 `Option<String>`。旧 JSON 向后兼容。
> 简明迁移表见 [`../user-manual/migration.md`](../user-manual/migration.md)。

---

## 🎯 亮点

- **`proxy.mode = "system"`**：catcher 自动从 OS 读取系统代理——调用方无需知道代理地址
- **Clash/VPN 开箱可用**：`detect_system_proxy()` 读取系统代理（含 SOCKS5），`socks5://` 自动转 `socks5h://` 兼容 fake-IP

---

## ✨ 新增 API

| API | 平台 | 说明 |
|-----|------|------|
| `ProxyMode` enum | core | `Manual`（默认）/ `System`（自动检测） |
| `ProxyConfig.mode` | 全平台 | 新增字段，`#[serde(default)]` 向后兼容 |
| `detect_system_proxy()` | catcher-dns | 从 OS 读取系统代理，供 http/ws 共享 |

## ⚠️ 行为变更

| 变更 | 旧行为 | 新行为 |
|------|--------|--------|
| `ProxyConfig.url` | `String` | `Option<String>` — 旧 JSON `{"url":"..."}` 仍可反序列化 |
| scheme 补齐 | `socks5://` | `http://`（更通用，SOCKS 代理须明确标注） |

## 🔄 Internal

- `detect_system_proxy()` 置于 `catcher-dns`，http/ws 共享单份实现
- WS `networkChanged` 非 System 模式消除多余 `config.clone()`

## 📋 升级清单

- [ ] 若直接构造 `ProxyConfig { url: "..." }`：改为 `ProxyConfig { url: Some("...".into()), ..Default::default() }`
- [ ] 若走 JSON/napi：无需改动（`#[serde(default)]` 自动兼容）
